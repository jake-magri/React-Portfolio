# Magri Exterior Services archive

The landing page, component, styles, and original image assets are preserved here outside Next.js routes and the public asset directory. The former /exterior-services/ URL returns the site's 404 page.

To restore the page, move the contents of this archive's src and public directories back to the matching repository directories, restore the footer link, and restore the exterior-services layout exception in src/pages/_app.js from Git history. Run npm run build to regenerate the sitemap.

Files in this archive remain accessible through the GitHub repository according to its visibility settings.
